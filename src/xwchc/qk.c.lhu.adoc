[#qk_c_lhu]
==== qk.c.lhu

Synopsis::
Load unsigned halfword, compressed (register-offset).

Mnemonic::
qk.c.lhu _rdpass:[`]_, _uimm_(_rs1pass:[`]_)

Encoding::
[wavedrom, , svg]
....
{reg: [
  {bits: 2, name: 0x2, attr: ['OP']},
  {bits: 3, name: 'rd`', attr: ['x8-x15']},
  {bits: 2, name: 'uimm[2:1]'},
  {bits: 3, name: 'rs1`', attr: ['x8-x15']},
  {bits: 3, name: 'uimm[5|4:3]'},
  {bits: 3, name: 0x1, attr: ['FUNCT3']}
], config: {bits: 16}}
....

The immediate offset is formed as follows:

[source,sail]
--
  uimm[XLEN-1:6] = 0;
  uimm[5:3]      = encoding[12:10];
  uimm[2:1]      = encoding[6:5];
  uimm[0]        = 0;
--

Description::
This instruction loads a halfword from the memory address formed by adding _rs1pass:[`]_ to the zero-extended
immediate _uimm_. The resulting halfword is zero-extended to XLEN bits and is written to _rdpass:[`]_.

[NOTE]
  _rdpass:[`]_ and _rs1pass:[`]_ are from the standard 8-register set x8-x15.

Operation::
[source,pseudo]
----
X(rdc) = EXTZ(load_mem[X(rs1c)+EXTZ(uimm)][15..0]);
----
