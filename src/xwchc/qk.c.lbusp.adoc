[#qk_c_lbusp]
==== qk.c.lbusp

Synopsis::
Load unsigned byte from stack, compressed (stack pointer-relative).

Mnemonic::
qk.c.lbusp _rdpass:[`]_, _uimm_(sp)

Encoding::

[wavedrom, , svg]
....
{reg: [
  {bits: 2, name: 0x0, attr: ['OP']},
  {bits: 3, name: 'rd`', attr: ['x8-x15']},
  {bits: 2, name: 0x0, attr: ['FUNCT2']},
  {bits: 4, name: 'uimm[3:0]'},
  {bits: 2, name: 0x0},
  {bits: 3, name: 0x4, attr: ['FUNCT3']}
], config: {bits: 16}}
....

The immediate offset is formed as follows:

[source,sail]
--
  uimm[XLEN-1:4] = 0;
  uimm[3:0]      = encoding[10:7];
--

Description::
This instruction loads a byte from the memory address formed by adding _sp_ to the zero-extended
immediate _uimm_. The resulting byte is zero-extended to XLEN bits and is written to _rdpass:[`]_.

[NOTE]
  _rdpass:[`]_ is from the standard 8-register set x8-x15.

Operation::

[source,pseudo]
----
X(rdc) = EXTZ(load_mem[X(sp)+EXTZ(uimm)][7..0]);
----
