[#qk_c_lhusp]
==== qk.c.lhusp

Synopsis::
Load unsigned halfword from stack, compressed (stack pointer-relative).

Mnemonic::
qk.c.lhusp _rdpass:[`]_, _uimm_(_sp_)

Encoding::
[wavedrom, , svg]
....
{reg: [
  {bits: 2, name: 0x0, attr: ['OP']},
  {bits: 3, name: 'rd`', attr: ['x8-x15']},
  {bits: 2, name: 0x1, attr: ['FUNCT2']},
  {bits: 4, name: 'uimm[3:1|4]'},
  {bits: 2, name: 0x0},
  {bits: 3, name: 0x4, attr: ['FUNCT3']}
], config: {bits: 16}}
....

The immediate offset is formed as follows:

[source,sail]
--
  uimm[XLEN-1:5] = 0;
  uimm[4]        = encoding[7];
  uimm[3:1]      = encoding[10:8];
  uimm[0]        = 0;
--

Description::
This instruction loads a halfword from the memory address formed by adding _sp_ to the zero-extended
immediate _uimm_. The resulting halfword is zero-extended to XLEN bits and is written to _rdpass:[`]_.

[NOTE]
  _rdpass:[`]_ is from the standard 8-register set x8-x15.

Operation::
[source,pseudo]
----
X(rdc) = EXTZ(load_mem[X(sp)+EXTZ(uimm)][15..0]);
----
