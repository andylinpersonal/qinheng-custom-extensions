== Custom Extensions

This document describes the custom ISA extensions defined by QinHeng. To avoid conflicts between mnemonics defined by different implementors of custom RISC-V extensions, each vendor-defined mnemonic is prefixed with a vendor-specific identifier in the form as `<vendor prefix> . <mnemonic basename>`. The vendor prefix for all mnemonics defined by community is `qk` (e.g., the `c.lbu`
instruction becomes `qk.c.lbu`).
